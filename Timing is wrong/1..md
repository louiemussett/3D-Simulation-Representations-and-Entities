# The exact inheritance formula

The relevant module is `src/trait-variation.js`.

Its central mechanism is:

```js
const parentMean = (key, fallback) => {
  const values = [mother?.[key], father?.[key]]
    .filter(Number.isFinite);

  return values.length
    ? values.reduce((sum, value) => sum + value, 0) / values.length
    : fallback;
};
```

So for each heritable characteristic, the system first calculates approximately:

[  
P = \frac{M + F}{2}  
]

where:

- (M) = mother's trait value
    
- (F) = father's trait value
    
- (P) = parental midpoint
    

If only one parent's value exists, it uses that one. If neither exists, it uses a defined fallback.

That means inheritance is genuinely dependent on **parental phenotype/trait values**, not an independent random draw.

# There is heritable variation around the parental value

The child is not simply an exact average.

The module generates Gaussian variation:

```js
const overall = clamp(
  gaussian(random),
  -2.75,
  2.75
);
```

and also generates divergence:

```js
const divergence =
  clamp(
    Math.abs(gaussian(random)) *
      (.48 + difficultPregnancyDivergence),
    0,
    2.8
  );
```

Eight trait-specific random deviations are then generated:

```js
const raw =
  Array.from({ length: 8 }, () => gaussian(random));

const mean =
  raw.reduce((sum, value) => sum + value, 0) /
  raw.length;

const deviations =
  raw.map((value) =>
    (value - mean) * divergence
  );
```

This is effectively providing **offspring variation around parental inheritance**.

It is not modelling explicit chromosomes, alleles or Mendelian loci. It is a quantitative-trait model.

That's scientifically an important distinction.

Your simulation currently resembles a simplified **polygenic quantitative inheritance model**, rather than a literal gene-by-gene genetic simulation.

# The actual offspring formula is approximately

For most multiplicative traits, the code uses:

```js
const broad = overall * .075;

const trait = (
  index,
  base,
  low,
  high,
  scale = .12
) =>
  clamp(
    base *
      (
        1 +
        broad +
        deviations[index] * scale
      ),
    low,
    high
  );
```

In mathematical form, approximately:

[  
T_c =  
\operatorname{clamp}  
\left[  
T_p  
\left(  
1+B+D_iS  
\right),  
L,H  
\right]  
]

where:

- (T_c) = child's trait
    
- (T_p) = mean parental trait
    
- (B) = broad offspring-wide variation
    
- (D_i) = variation specific to trait (i)
    
- (S) = trait-specific variation scale
    
- (L) = minimum permitted trait value
    
- (H) = maximum permitted trait value
    

For body size specifically:

[  
S=0.09  
]

and:

[  
0.62 \leq sizeTrait \leq 1.48  
]

So offspring tend to remain related to their parents while still exhibiting variation.

That is exactly the structure necessary for selection to accumulate across generations.
